# Simple Interest Calculator

A simple calculator that calculates simple interest given the principal amount, annual rate of interest, and time peroid in years.

## Purpose

The purpose of this project is to provide a straightforward, accessible tool to calculate simple interest and understand financial growth over time, while serving as a collaborative open-source project demonstrating Git and GitHub workflows.

## Formula

The formula used to calculate simple interest is:

```
Simple Interest = (Principal × Rate × Time) / 100
```

Where:
- **Principal**: The initial sum of money borrowed or invested.
- **Rate**: The annual rate of interest (in percentage).
- **Time**: The time duration for which the principal is borrowed or invested (in years).

## Example Calculation

Suppose you invest a principal amount of 1000 at an annual interest rate of 5% for a period of 2 years:

```
Simple Interest = (1000 × 5 × 2) / 100 = 100
Total Amount = Principal + Simple Interest = 1000 + 100 = 1100
```

## Instructions for Running simple-interest.sh

You can run `simple-interest.sh` using Bash or Git Bash in your terminal:

```bash
bash simple-interest.sh
```

**Example Inputs:**
```
Enter the principal:

Enter time period in years:

```

**Expected Output:**
